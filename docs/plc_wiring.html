배선도 — 컨베이어 셀 전체 연결

센서 12V 구동 통일 구성 (24V SMPS 생략). 전선은 총 13가닥 — 12V 세계 7가닥 + 듀폰 6가닥. 두 세계 사이를 넘어가는 전선은 0가닥이며, 신호는 PC817의 빛과 릴레이의 접점으로만 건너간다.

+12V 0V (12V 리턴) 센서 신호 (검정선) 3.3V 파이 GND GPIO 입력 신호 GPIO 출력 신호 ● = 접속점 / 단순 교차 = 비접속

신호 흐름 (한 사이클)

물체 도착→ 센서 검정선을 0V로 당김→ PC817 CH1 점등→ GPIO17 = %IX0.0→ 래더 3렁→ %QX0.0 = 0→ 릴레이 열림 = 컨베이어 정지→ Python: object_arrived 읽기→ 로봇 집기→ Python: pick_done 쓰기→ 컨베이어 재가동

조립 순서 · 통전 전 체크

조립 순서

  1. 모든 전원 뽑은 상태에서 배선 (12V 어댑터, 파이 USB-C 전부 분리)
  2. 12V 세계 먼저: 분기점 나사단자 → 센서 3선 → PC817 입력측 → 릴레이 부하측 → 컨베이어 (①~⑦)
  3. 듀폰 6가닥 (⑧~⑬)
  4. 릴레이 스위치 H 위치 확인
  5. 12V만 투입 → 센서 앞에 손: 센서 LED + PC817 CH1 LED 점등 확인
  6. 파이 부팅 → GPIO 레벨 확인 → OpenPLC Runtime 기동

통전 전 체크

  • 파이에 꽂힌 선이 듀폰 6가닥 + USB-C뿐인가 (12V 선이 파이에 닿으면 파손)
  • PC817 입력 극성: IN1 = +12V / G = 센서 검정 (반대면 LED 역방향 = 무반응)
  • 릴레이 부하측이 COM–NO인가 (NC에 물리면 논리 반전)
  • 컨베이어 배럴 극성 (통상 센터 + — 어댑터 라벨 실측)
  • 릴레이 검은 몸체 인쇄 정격 ≥ 3A (12V/모터 전류 대비)
미확정 2가지 — 배선은 그대로, 값만 나중에 확정
  • GPIO17 / GPIO27은 예시. OpenPLC v4의 라즈베리파이 GPIO 매핑(%IX0.0/%QX0.0이 어느 물리 핀인지)을 확인한 뒤 그 핀으로 꽂는다 — 듀폰이라 옮기는 건 10초.
  • PC817 점퍼 방향은 실측 확정. 부팅 후 센서에 손 대고 GPIO가 HIGH 되는 쪽으로. 반대여도 래더에서 NOT 하나로 해결 가능.
